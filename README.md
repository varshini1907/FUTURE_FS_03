Moonlight Cafe Website

Moonlight Cafe is a modern and responsive café-themed website designed to create a cozy and aesthetic user experience. The project focuses on clean UI design, smooth navigation, and an elegant café-inspired layout.

🔗 Live Demo : https://moonlight-caf.netlify.app/

📌 Features
- Responsive Design
- Modern Café-Themed UI
- Interactive Navigation
- Menu Section
- About Us Section
- Contact Section
- Smooth Hover Effects
- Clean and User-Friendly Layout

 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

 🎯 Project Objective
The main objective of this project is to design an attractive and responsive café website that provides users with a visually pleasing browsing experience while showcasing frontend development skills.

 ✨ Highlights
- Aesthetic dark-themed design
- Smooth animations and transitions
- Fully responsive across devices
- Simple and clean code structure

 🚀 Learning Outcomes
Through this project, I improved my understanding of:
- Responsive Web Design
- Frontend Development
- UI/UX Design Principles
- Website Layout Structuring
- CSS Styling and Animations
